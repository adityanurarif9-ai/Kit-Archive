# Kit-Archive
bismilah

Kit Archive adalah katalog jersey klub sepak bola Eropa. Jelajahi rak berdasarkan klub dan musim, bandingkan dua jersey, bagikan hasil perbandingan, dan simpan daftar incaran di browser.

[Demo publik Kit Archive](https://kit-archive-madrid-adit.flexbox-code.chatgpt.site)

## Menjalankan di komputer

Buka `dist/index.html` di browser. Untuk menjalankan lewat server lokal, jalankan perintah berikut dari folder repo dan buka [localhost:8000](http://localhost:8000).

```sh
python -m http.server 8000 --directory dist
```
